APP FLOW DOCUMENT (FOR ANTIGRAVITY)
Context

This app is a slow-paced emotional discovery game for adults (15+).
It is not a chat app and not instant messaging.
The goal is to keep all 4 users active together, building curiosity and trust over days.

1️⃣ ENTRY FLOW (FIRST TIME USER)
Step 1: Login

Google Sign-in

Fast, no friction

Step 2: Mandatory Profile Setup

User must complete:

Date of Birth (15+ hard gate)

Gender (locked, cannot be changed easily)

Profile photo (mandatory but hidden initially)

Name / alias

A few personality preferences

👉 Important:
Profile photo, name, etc. are stored but NOT shown immediately.

This creates future reveal hooks.

2️⃣ ROOM MATCHING FLOW (CRITICAL)

Users are placed into groups of 4

2 male + 2 female ONLY

No group starts unless fully filled

If users join early:

They see “Waiting for others to join”

Calm waiting UI (not boring, not stressful)

👉 This ensures:

No imbalance

No lonely player

No broken ecosystem

3️⃣ HOME SCREEN (GAME WORLD)

Once group is full:

Users enter the island world

See 4 avatars (app-generated at first)

No chat

No names

No photos

Only interaction:
👉 Mystery / Question Cards

4️⃣ QUESTION SYSTEM (VERY IMPORTANT)
Problem We Solve

Many users:

don’t know what to ask

feel pressure

rage-quit if stuck

Solution: Guided Question System

Each day, user gets:

System-suggested questions

Option to write their own (optional)

Example Suggested Questions:

“What would be your reaction if I choose to work after marriage?”

“How would you feel if I make reels or content online?”

“What matters more to you: peace or ambition?”

“How do you react when someone disagrees with you?”

“What is something you respect but don’t openly talk about?”

👉 Users select, not invent.
This prevents rage quit.

5️⃣ ANSWERING FLOW

One user’s question opens for others

Others respond thoughtfully (no rush)

No one sees answers instantly

After submission → soft confirmation

Answers are interpreted, not judged right/wrong.

6️⃣ POINT & IMPRESSION SYSTEM (HOOK)

After answers:

Question owner reacts privately:

“Understood me”

“Interesting”

“Didn’t resonate”

This gives connection points (hidden score).

👉 No public scores
👉 No comparison
👉 No shame

7️⃣ DAILY HOOK (WHAT UNLOCKS TOMORROW)

At end of each day, user sees:

“Tomorrow, something new may unlock if your answers resonate.”

Possible unlocks:

See name

See profile photo

Unlock limited messages

Unlock reactions

👉 This brings users back daily.

8️⃣ NOTIFICATION SYSTEM (GAME CRITICAL)

Notifications must be:

Fast

Clear

Specific

Examples:

“Your group is ready. A new mystery awaits.”

“Someone answered your question.”

“Tomorrow, a reveal may happen.”

“Final ceremony is approaching.”

👉 No generic notifications.
👉 Notifications must feel like events, not reminders.

9️⃣ ACTIVITY ENFORCEMENT (ANTI-OFFLINE RULE)
Problem

If 1 user goes inactive:

other 3 get frustrated

ecosystem breaks

Solution

Each user has a daily activity window

If inactive too long:

System nudges them

Then warns

Then safely removes them

Removed user:

does not harm others

group gets replacement or resolution

👉 No silent inactivity allowed.

🔟 PROFILE REVEAL FLOW

Profile details are progressively revealed:

Avatar only

Name

Profile photo

Limited chat

Full chat (if mutual)

Users feel:

“I earned this access.”

1️⃣1️⃣ REVEAL CEREMONY (END OF CYCLE)

After ~7 days:

Calm ceremony screen

Summary of connections

Users choose who to continue with

No rejection screen.
No “match failed” feeling.

Even no connection feels respectful.

1️⃣2️⃣ WHY USERS STAY (RETENTION LOGIC)

Users return because:

Curiosity about tomorrow

Fear of missing unlock

Emotional validation

Group dependency

Calm, safe environment

1️⃣3️⃣ IMPORTANT RULES (NON-NEGOTIABLE)

No instant chat

No instant profile reveal

No public scores

No harassment

No pressure

No fast pacing

🧠 CORE PHILOSOPHY (FOR DEV TEAM)

This app succeeds when users feel
safe, curious, and gently hooked — not excited or rushed.

END OF FLOW DOCUMENT
